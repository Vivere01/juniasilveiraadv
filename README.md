# Dra. Júnia Silveira — Site Institucional

Site institucional da Dra. Júnia Silveira, especialista em Direito do Consumidor, Bancário e Digital.

## 🚀 Deploy na Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Vivere01/juniasilveiraadv)

O projeto é um site estático (HTML puro + Tailwind CSS via CDN) e está configurado para deploy imediato na Vercel.

### Deploy manual
1. Acesse [vercel.com](https://vercel.com) e faça login
2. Clique em **Add New → Project**
3. Importe o repositório `Vivere01/juniasilveiraadv`
4. Clique em **Deploy** — nenhuma configuração adicional necessária

## 📁 Estrutura

```
/
├── index.html      # Página principal (site completo)
├── vercel.json     # Configuração de deploy
└── README.md       # Este arquivo
```

## ✨ Funcionalidades

- Hero com carrossel/ticker animado
- Seção de especialidades (Consumidor, Bancário, Digital)
- Seção Sobre com estatísticas
- Seção de Contato com formulário e mapa do Google
- Botão WhatsApp flutuante
- Ícone Instagram no rodapé
- Design responsivo (mobile-first)
- Dark mode premium

## 🛠 Tecnologias

- HTML5 semântico
- Tailwind CSS (via CDN)
- Google Fonts (Playfair Display + Manrope)
- Material Symbols (Google Icons)
- CSS puro para animações (ticker, float, fade-in)
